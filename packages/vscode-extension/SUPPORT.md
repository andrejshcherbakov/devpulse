# Support

Before opening an issue, run **DevPulse: Show Diagnostics** and review
**Output → DevPulse**. Never include an API key in a report.

- Bug reports and feature requests: <https://github.com/andrejshcherbakov/devpulse/issues>
- Setup and self-hosting: <https://github.com/andrejshcherbakov/devpulse/tree/main/docs>
- Privacy policy: [PRIVACY.md](./PRIVACY.md)

Include the DevPulse version, VS Code version, operating system, and the
relevant log lines with workspace names, paths, remote URLs, and commands
redacted when necessary.
